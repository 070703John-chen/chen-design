03 · 版式

原创版式设计

不依赖商品原图，从构图、色彩与文案三个维度建立可延展的视觉方向，同一品类输出六套独立版式。

6套原创版式 6种视觉语言 1024×1024可直接上架 文字全部可改
C1 · 场景叙事
一束光，落在桌面
满幅实景压住上半，标题沉到底部。这一版讲的是「光落到桌面的角度」，不是卖点词。
护眼台灯场景位暖调
C2 · 参数解构
柜下的一条光带
深色底压住画面，用引线标注材质、结构与出光面，信息层级清晰。
LED橱柜灯标注式信息设计
C3 · 极简留白
把光做成一个形状
去除促销噪音，仅保留产品与核心文案，以留白建立视觉焦点。
LED球泡灯浅底大标题
C4 · 光影产品
超薄，也要有存在感
薄型产品本身没有体积，用同心光环把空间撑起来，这是专为它定的一套画法。
LED吸顶灯暗底光环
C5 · 拆解对照
可调角度的射灯
左侧呈现画面，右侧呈现参数表，用信息设计替代口号式表达。
LED射灯左右分栏参数表
C6 · 品牌延展
光是可以被设计的
同一个产品换一种表达方式，就是另一张作品。这一版练的是把它当品牌资产而不是当商品图。
LED灯带标识slogan

05 · 复刻与优化

版式拆解与迁移重建

将主图拆解为照片、平面、美术字、文字四层，抽出可替换字段，再以自有产品完成一次重建验证。

4层拆解 · 照片 / 平面 / 美术字 / 文字 1份元素规格表（位置 / 颜色 / 字号 / 可否改字段） 1条命令换 SKU 重跑
1照片层产品抠图后向外扩展 12px 光晕，边缘不残留背景色
2平面层色块与渐变以 CSS 绘制，促销色仅用于金额
3美术字层3D 字体与书法字抠为带透明通道的 PNG，不以近似字体替代
4文字层全部文字采用 SVG text，价格／活动／型号保留为字段
LAYER 1

照片层

产品照片不重画，直接抠图搬过来，只抹掉要重排的标题。

拆解结论产品不重绘。抠图后向外补 12px 光晕，边缘不吃背景色。
照片层可原样迁移
应用于自有产品白底实拍直接作底图，仅补暖光晕。
LAYER 2

平面层

色块和渐变用 CSS 画，底部渐变从原图反推，大白字抠掉后拟合回填。

拆解结论促销色只给金额，其余走中性色板，价格位永远留空。
色板可按原图复现
应用于自有产品替换为自有暖金色板，价格位仍保留在文字层。
LAYER 3

3D 美术字层

书法字、徽章、logo 无开源字体等价物，按背景色抠成带 alpha 的 PNG。

拆解结论美术字不找近似字体——找到了也一定不像，直接抠。
美术字可直接抠取
应用于自有产品抠取自有标题美术字，沿用同一套抠图方法。
LAYER 4

文字层

文字全部采用 SVG text，y 为基线，textLength 锁定字宽。

拆解结论文字必须可编辑，价格、活动、型号保留为字段，不并入图像。
文字宽度与原图一致
应用于自有产品换货仅替换字段与色值，不重排版式。

自有产品主图设计

以自有 LED 硅胶灯带构建促销版式，覆盖平台主图核心信息位，800×800 平台直出。

800×800平台直出尺寸 1x + 2x双规格交付 4份可复用资产 0处编造的产品信息
交付规格
1x800×800，平台直出尺寸
2x1600×1600 源文件随交付
可编辑改价、改活动、换图均在源件内完成
RULE 1

让产品自己成为光源

自发光产品白底拍出来，发光感就消失了，必须暗场。

缩到 200px 宽仍看得出在发光
RULE 2

色温即钥匙

暖色产品配中性白底＝背景残留；冷色产品同理。抠图按这个判。

只在轮廓外 12px 环带内清理
RULE 3

深底文字必须描边

标题采用金色渐变加深色描边外扩，小字不加描边以保证清晰度。

stroke + paint-order
RULE 4

促销色只给金额

全图 4 色 + 1 强调色，黄色只出现在价格上。

强调色超过 3 种将削弱层级

顺带产出 4 份可复用资产：可编辑源件 index.html（改价改活动换图都在这里）、底图提示词（暗场补光，含负面词与 8 条评审项）、《暗场自发光产品主图设计原则》入库、抠图脚本（GrabCut + 环带清理 + 底缘暖化）。 图像中的产品描述均来自原图（COB 连续均匀发光 / 硅胶 / 立式线轴 / 双面 PCB / 暖白）。价格、品牌、活动与角标 4 处未作虚构，均设置为明确的占位字段，并附「填写内容与依据」清单。

07 · 批量套图

多品类套图批量输出

同一份数据表驱动全部图位与照明品类，逐张校验后交付。

42张全量通过校验 24张精选入册 11张不合格被拦下重做 1份数据表驱动全部图位
精选 24 张 · 点任意一张放大 深底＝卖点战场　白底＝产品展示位　附图按参数 / 安装 / 对比 / 细节分版
1数据层› 2模板层› 3形态层› 4校验层› 5落位层
展开四条踩坑规则
RULE 1

绑定必须用键

最早用「数组下标＝文件名里品类首次出现顺序」绑文案。品类表一换，7 个品类里 5 个张冠李戴，脚本只比长度不比名字，静默错位。

键＝品类名＋键＝图位，错字直接报错退出
RULE 2

形态要钉死

提示词写「条形橱柜灯」，生成器照样画成圆形吸顶灯。靠形容词压不住，得把形态和场景当锚点拼进去。

换品类只加一条，不改模板
RULE 3

落位靠测量

白底图标题区 + 底部条占掉 55% 画布，高瘦产品怎么摆都会被压到灯头或螺口。

逐行建模量背景，不目测
RULE 4

坏底图不硬上

逐张审全部底图，抓出 2 张货不对板、9 张带 AI 乱码、2 张产品占比不达标，全部退回重出。

判据是代码不是眼睛

价格、品牌、活动、角标与灯带长度 5 处未作虚构，均设置为占位字段，并附填写清单。BRAND.yaml 中的 5M/16.4FT 为示例值而非实测值，因此灯带长度保持留空。源件包提供唯一编辑入口 index.html：浏览器内改价、改文案、实时预览，并一键导出 slots.json。

08 · 流水线实测

版式流水线可复现验证

六张参考图抽象为三套版式体系，按真实画布比例输出，文字全部可改，交付两种版本。

6张参考图 3套版式体系 2种交付版本 1条命令完成

展开四条铁律、负结果与诚实边界
RULE 1

挖字掩膜用文字自身 fill 色

用「与区域众数色差异大」当判据时，小区域的众数色会被文字本身带偏，把胶囊底、价卡底一起挖掉，渲出来是白块。

掩膜＝文字自己的填充色
RULE 2

背景回填用留出法选算法

判据不能是「重建结果和原图差多少」——那一格是字不是背景，越像字越准。留出法：随机挑已知背景像素当考卷，给 inpaint 和多项式拟合打分。

六张实测 inpaint 全部胜出
RULE 3

寻优的当前值必须进候选集

否则越寻越差：候选里没有现值时，最优解必然比现值差，引擎却照样写进 HTML（R2 首次寻优 y 值 125→127，误差反增）。

现值永远在候选集里
RULE 4

指标要和交付物本身对账

打包脚本从 spec 重新生成时会退化成打回前的值。交付前加一道验收脚本，把交付包重渲一遍跟报告逐张对照——第一跑就抓到两处不一致。

交付前自动对账，抓出两处不一致

负结果也记：为让 R5 的白字鬼影消失，给掩膜加「多膨胀 1~2px」，实测 R2/R3/R4/R5 全部变差（R5 反而更差）。原因：吃掉边缘的同时也吃掉周围背景，inpaint 的洞更大、拖出来的糊更多。参数保留在引擎里但默认关闭。 诚实边界：这六张是复刻稿，是方法论证明，不是原创设计，不作为原创作品对外展示。非文字部分与原图一致，说明分层本身是干净的——素材层和照片层逐像素还原，残差 100% 来自字体替代。字体替代是这套方法的天花板，要突破只能上商业字体授权或自建字体。

09 · 方法沉淀

设计方法资产化

将流程固化为模板、脚本与评审清单，形成可复用的生产标准，更换品类无需从零重建。

1定量拆解› 2出底图› 3可编程排版› 4自动校准› 5评审› 6沉淀
同一条套图流水线覆盖七个照明品类 每一张均可单独上架

量化 > 目测

所有坐标、色值与字宽均以像素测量为准，不依赖目视对齐。

✗ 目测对齐，版本迭代即产生偏移
✓ 脚本自动比对，2~3 轮内收敛

像素素材优先于字体替代

3D 美术字、书法字与品牌标识均无开源字体等价物，采用抠图可与原图对齐。

✗ 以近似字体替代
✓ 抠图 + 实心裁切兜底

还原稿不作为原创作品

竞品还原仅作方法论验证，原创产出须落在自有产品上。

✗ 以复刻稿充当作品集
✓ 拆解卡 + 自研版式 + 自有产品

不编造产品事实

价格、品牌、活动与性能宣称均需有据，缺失信息一律留空占位，不做推测。

✗ 使用「护眼 / 无频闪」等无依据宣称
✓ 虚线占位 + 填写清单
